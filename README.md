# Chirank — Developer Portfolio

A responsive personal portfolio showcasing my background, skills, and featured work.
Built with semantic HTML and Tailwind CSS.

## Overview

Single-page portfolio with a sticky navigation bar, hero section, about, skills,
featured project, journey timeline, contact form, and footer. Light, mobile-first
design with subtle transitions and keyframe animations.

## Technologies

- **HTML** — semantic structure (`header`, `nav`, `main`, `section`, `footer`)
- **Tailwind CSS** — layout (Flexbox, Grid), spacing, responsive breakpoints, hover states
- **Custom CSS** — design tokens, transitions, keyframe animations, media queries
